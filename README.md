# Vertex — Ultimate JEE Practice Platform 🚀

**Vertex** is a high-performance, open-source web application designed specifically for **JEE Main & Advanced** aspirants. It combines a premium design aesthetic with data-driven study tools to help students achieve mastery in Physics, Chemistry, and Mathematics.

[![Live Status](https://img.shields.io/badge/Live-jeevertex.netlify.app-6366f1?style=for-the-badge)](https://jeevertex.netlify.app)
[![Tech Stack](https://img.shields.io/badge/Tech-Vanilla_JS_|_Firebase-emerald?style=for-the-badge)](#)

---

## ✨ Core Features

### ⚡ Rapid Fire Mode
Test your real exam speed. Answer as many questions as possible in 120 seconds. Earn combo streaks and climb the speed-rankings.

### 🎯 Custom Tests
Build your own mock exams. Select specific subjects, chapters, and difficulty levels. Set per-question or total-time limits to simulate any exam environment.

### 📚 Spaced Repetition (SRS)
Vertex uses an advanced algorithm to track your learning. It automatically identifies which chapters you're forgetting and marks them for review, ensuring maximum long-term retention.

### 🏆 Global Leaderboard
Sign in with Google to sync your progress. Compete with students worldwide across three metrics: **Best Streak**, **Questions Solved**, and **Overall Accuracy**.

### 📊 Deep Analytics
Understand your weaknesses. Vertex identifies your 5 weakest chapters and tracks your accuracy trends over time using real-time charting.

## 🎨 Design Philosophy: "Premium Glassmorphism"

Vertex is built for long study sessions. The UI features:
- **Zero Distraction:** Clean, focused interfaces for test-taking.
- **Glassmorphism:** Layered, semi-transparent cards with 20px background blurs.
- **Micro-Interactions:** Smooth, physics-based animations for every button and selection.
- **High-End Typography:** Utilizing *Syne* for bold headers and *Inter* for maximum readability.

---

## 🛠 Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Variables & Animations).
- **Backend:** Firebase Authentication (Google OAuth), Cloud Firestore (NoSQL), Firestore Security Rules.
- **Formula Rendering:** KaTeX (High-speed TeX math rendering).
- **Charts:** Canvas-based dynamic accuracy tracking.
- **Deployment:** Netlify with automated CI/CD.
